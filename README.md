## A better home screen for your TV.

**HOME.iO TV** dan **HOME.iO Lite** menghadirkan pengalaman Android TV, TV Box, dan STB dengan launcher yang modern, responsif, dan dirancang agar nyaman dikendalikan menggunakan remote.

Navigasi D-Pad yang terarah, tampilan adaptif, kontrol perangkat, wallpaper, serta pembaruan aplikasi dalam satu tempat.

## ⚙️ Kompatibilitas

| Komponen | HOME.iO TV | HOME.iO Lite |
|---|---|---|
| Minimum Android | 7.0 / API 24 | 6.0 / API 23 |
| Target penggunaan | Android TV, TV Box, STB, perangkat Android | Perangkat Android 6+ yang kompatibel |
| Navigasi remote | D-Pad | D-Pad |
| Arsitektur | Mengikuti ABI yang tersedia pada APK rilis | Mengikuti ABI yang tersedia pada APK rilis |

Kompatibilitas akhir tetap bergantung pada ABI, firmware vendor, fitur Android yang tersedia, dan izin perangkat.

## 🚀 Cara instalasi

1. Pilih edisi yang sesuai dengan versi Android perangkat.
2. Unduh APK dari halaman rilis resmi di atas.
3. Buka file APK melalui File Manager.
4. Jika diminta, izinkan instalasi aplikasi dari sumber tersebut.
5. Lanjutkan instalasi dan buka HOME.iO.

**Tips:** Jangan menghapus edisi utama saat memasang Lite. Keduanya menggunakan package ID berbeda sehingga dapat berdampingan.
