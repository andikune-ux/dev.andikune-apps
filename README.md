**HOME.iO TV** dan **HOME.iO Lite** menghadirkan pengalaman Android TV, TV Box, dan STB dengan launcher yang modern, responsif, dan dirancang agar nyaman dikendalikan menggunakan remote.

## 🚀 Cara instalasi

1. Pilih edisi yang sesuai dengan versi Android perangkat.
2. Unduh APK dari halaman rilis resmi di atas.
3. Buka file APK melalui File Manager.
4. Jika diminta, izinkan instalasi aplikasi dari sumber tersebut.
5. Lanjutkan instalasi dan buka HOME.iO.

**Tips:** Jangan menghapus edisi utama saat memasang Lite. Keduanya menggunakan package ID berbeda sehingga dapat berdampingan.
