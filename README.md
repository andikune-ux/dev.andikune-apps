## ⚙️ Cara Instalasi (Android TV / STB)

1. Unduh file `.apk` melalui tautan di tabel atas.
2. Pindahkan file ke Flashdisk (jika mendownload dari PC), lalu colokkan ke TV.
3. Buka **File Manager** di TV, cari file APK tersebut, lalu klik untuk menginstal.
4. Jika muncul peringatan keamanan, pilih **"Izinkan dari sumber ini" (Allow from this source)**.
5. Klik **Install** dan tunggu hingga selesai.

*(Catatan: Karena aplikasi diunduh dari luar Google Play, TV kamu memerlukan izin "Unknown Sources" untuk menginstal APK)*.
