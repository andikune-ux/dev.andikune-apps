<div align="center">
  <h2>⚙️ Panduan Instalasi</h2>
</div>

1. Klik tombol **UNDUH APK TERBARU** di atas.
2. Pindahkan file `.apk` ke Flashdisk (jika mendownload dari PC), lalu colokkan ke TV.
3. Buka **File Manager** bawaan TV, cari file APK tersebut, dan klik untuk menginstal.
4. Jika muncul peringatan keamanan, pilih **"Izinkan dari sumber ini" (Allow from this source)**.
5. Tunggu proses instalasi selesai dan buka aplikasi **HOME.iO TV**.
