  <h2>🚀 Panduan Instalasi</h2>
</div>

1. Klik tombol **⬇️ DOWNLOAD HOME.iO TV APK** di bagian paling atas.
2. Pilih file `.apk` terbaru dari daftar rilis, lalu unduh.
3. Pindahkan file ke Flashdisk (jika mengunduh via PC) lalu colokkan ke TV. *(Jika TV mendukung browser, bisa langsung unduh dari TV).*

5. Jika muncul peringatan **"Unknown Sources"**, pilih **Setelan (Settings)** lalu centang **Izinkan dari sumber ini (Allow from this source)**.

7. Buka aplikasi HOME.iO TV, berikan izin yang diminta, dan nikmati pengalaman baru!
